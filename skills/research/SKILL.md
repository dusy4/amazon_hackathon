# Research

## Source order

1. Official Amazon/AWS/Alexa/Fire TV/Ring/IMDb docs
2. Devpost rules/resources/FAQ
3. Official GitHub repos
4. Official third-party docs
5. Secondary/community sources only if needed

## Record material findings in Notion

Include:
- question
- finding
- source URL
- date
- public / preview / partner-gated / deprecated / unclear
- feasibility A-F
- previous assumption if changed
- impact on architecture/product

## Wording

Do not overclaim absence.

Use:
> “No public developer interface was found in the official sources searched as of [date].”

## If research changes the canonical understanding

Update `v2`.

If it opens a new idea/path, also update `Product Exploration — Feature Base`.
