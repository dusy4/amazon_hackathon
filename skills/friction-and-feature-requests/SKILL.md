# Friction + Feature Requests

Use `Dev + Friction Log`.

## Product Feedback

For every Amazon tool/API/SDK actually used:
- what it was used for
- what worked well
- what needs work
- onboarding
- reliability/performance
- missing capability
- whether we would build with it again

## Friction

Only after a real implementation attempt.

Capture:
- task attempted
- steps
- expected
- actual
- exact error/log
- severity
- workaround
- actionable suggestion

Never fabricate friction.

## Feature Request

May come from research or implementation.

Capture:
- feature requested
- what should change
- why it matters
- concrete use case
- current workaround
- impact
- priority: Critical / Important / Nice-to-have
- evidence/docs
- related friction if any

Whenever a limitation appears, ask separately:
1. Is this reproducible friction?
2. Is there a concrete Amazon feature request?
