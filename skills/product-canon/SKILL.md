# Product Canon

Use whenever work affects product behavior, use cases, UX, architecture, or feature scope.

## Rule

Do not prune the product because:
- an API is unavailable
- an integration is gated
- implementation is expensive
- latency is high
- a workaround is required

Instead:
1. preserve the feature;
2. update feasibility;
3. record the best current implementation path;
4. record alternatives;
5. update `v2` or `Product Exploration — Feature Base`.

## Product definition

Semantic Playback is an agentic context layer for video:

**Understand → Ground → Act → Remember → Continue**

Core differentiation:

**semantic reference → temporal grounding → real player/action execution → memory and downstream workflows**
